# Claude Code memory (template)

Claude Code can keep notes between sessions in
`~/.claude/projects/<project-folder>/memory/`. Each note is one Markdown file,
and `MEMORY.md` is the index Claude reads at the start of every session.

You don't need to create anything: Claude writes these itself as it learns how
you work. The two files here show the format if you want to seed a few notes.
Memory is personal, so this repo never ships real notes.
